# Budget Tracker

A personal budget and expense tracker built as a progressive, multi-week
**web development** project (HTML, CSS, and eventually JavaScript). Each
week adds a new layer of functionality, starting from a static HTML/CSS
layout and building toward a fully interactive application.

## Tech Stack

- HTML5
- CSS3
- JavaScript (coming in later weeks)

## Project Status

Currently in the frontend structure and styling phase. No JavaScript
functionality is connected yet.

## Features (so far)

- Page structure with a header, an "Add Expense" form, and an expenses table
- Expense entry form with fields for name, amount, and category (dropdown)
- Expenses displayed in a structured HTML table with sample data
- Collapsible "How to use this tracker" instructions section
- Embedded logo image and a budgeting tip video
- Styled with CSS using element, class, ID, descendant, child, and
  pseudo-class selectors (hover, focus, nth-child, not, first-child)

## Files

- `index.html` — the page structure and content
- `style.css` — all styling, including table formatting and interactive states

## How to view it

Clone or download this repository, then open `index.html` directly in your
browser. No build steps or dependencies required at this stage.

## Planned upgrades (future weeks)

- JavaScript functionality for adding expenses dynamically
- Form validation
- Calculations (totals, category breakdowns)
- Data persistence
